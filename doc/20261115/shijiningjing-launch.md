# 拾记凝境上线记录（2026-11-15）

## 1. 结论

- 产品「拾记凝境」已上线：<https://stars-page.com/Percolation/>，手机号验证码登录，账号与星页通用。
- 界面选定方案 2「双境工作区」，接入真实的记忆系统后端；其余四套方案作为备选存档，仍可在 IP 直连地址 `/ningjing/` 查看。
- 每个登录用户自动获得一份独立的记忆空间，彼此不可见；每晚自动把当天的随手记凝练成「近况」。

## 2. 用户能做什么

| 动作 | 体验 |
| --- | --- |
| 记录 | 想到什么随手记一句，不用分类；记下的一句化作光点流向询问侧，表示已被 AI 吸收 |
| 询问 | 用一句话问记过的事；输入问题时，记录侧会实时亮起可能用到的记录；回答下方有「依据 N 条记录」，点一下能定位原话 |
| 追问 | 遇到 AI 不认识的称呼或指代，它会反问一句；用户补一句后立刻作答，这句补充也会被记住，下次不用再解释 |
| 近况 | 每晚整理后，「我的近况」里按主题汇总近期的约定、健康、常去地点等 |
| 两端 | 电脑上光标在哪一侧，哪一侧就舒展为主工作区；手机上左右滑切换「记录」和「询问」两张卡片 |

## 3. 方案架构（非技术版）

```
浏览器（stars-page.com/Percolation）
   │  同一个域名，自动带上星页登录状态
   ▼
星页站点入口（Nginx）── /Percolation/ ──▶ 拾记凝境服务（网页 + 接口，本机常驻）
                                         │  向星页确认「这是谁」
                                         │  每个账号一份独立记忆空间（数据库行级隔离 + 独立文件目录）
                                         ▼
                              记忆系统：即时记录与检索（白天）、夜间整理（每晚 03:30）
```

- **复用星页账号**：不另建账号体系。拾记凝境只向星页询问当前登录的是谁，不读星页数据，也不经手密码与验证码校验。
- **隔离**：每个账号首次进入时自动开一个记忆空间；数据库层面强制按账号隔离，网页无法通过改请求访问他人数据。
- **成本护栏**：每个账号每 24 小时最多询问 200 次、记录 1000 条；整理只在夜间统一执行，网页不能手动触发。

## 5. 验收

- 自动化测试 50 项全部通过（含线上鉴权模式下的接口全链路、跨账号隔离）。
- 浏览器走查（全新账号、真实模型作答）18 项全部通过：空状态 → 连记 5 条 → 电脑端切换伸缩 → 边问边浮现 → 作答带依据 → 陌生称呼追问 → 补一句后作答 → 刷新后历史完整还原 → 手机端滑动切换与边签计数。
- 线上冒烟：用星页测试账号的临时会话走通「登录识别 → 自动开户 → 记录 → 询问（约 8 秒作答）」，测试后已吊销会话并删除测试数据。
- 夜间整理实测：11 条随手记整理出 3 个主题（会面安排、健康、常去地点），近况正常展示，单次整理约 0.4 元。

- 重启拾记凝境服务会有约 3 秒不可用，正在进行的询问会中断。

## 7. 后续建议

1. **埋点与指标**：首条记录率、首次询问率、次日留存、追问补一句比例；为备选方案 AB 测试打基础。
2. **首日体验**：新用户当天没有「近况」，可考虑在记录满一定条数后提前做一次轻量整理。
3. **回答流式输出**：目前一次性返回，慢时约 8–20 秒，靠思考文案过渡。
4. **深色模式**：可参考备选方案 3「极夜聚光」。
5. **星页入口**：在星页首页或个人菜单加一个拾记凝境入口，目前只能直接访问链接。
