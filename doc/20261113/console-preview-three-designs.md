# 控制台前端预览（第二轮）

第一轮三套偏视觉风格，未采纳。第二轮按知微后台风格重做：浅底白卡片、单一主色、表格与标签为主，强调干净、分区清楚、关键信息突出、配置可直接操作。

## 三套方案

| 端口 | 方案 | 适合 |
|------|------|------|
| 3001 | 经典侧栏 + 抽屉 | 与现有知微后台一致，上手零成本 |
| 3002 | 顶栏 + 主从布局 | 频繁在节点之间切换对比配置 |
| 3003 | 设置中心 | 逐个节点细看、细改，像填设置表 |

## 内容（三套一致）

- 整体架构：五层架构图（可点击看说明）、检索 / 整理 / 内核循环三条工作流（逐步查看输入输出）
- Agent 配置：2 个 Agent、6 个节点；模型槽、轮次、温度、工具开关、Skill、Prompt 可编辑；工具按只读 / 写入 / 删除 / 沙箱 / 数据库标色；保存前弹出改动对比
- 上下文管理：每个节点的上下文按注入顺序排列（固定 / 每次注入 / 按需出现三色区分），完整 system prompt 标出运行时追加部分，Skill 正文与加载方式
- 调试台：录入、提问、澄清、整理、重建索引的模拟运行

## 第三轮：融合版（3004，选定方向）

- 整体用 3003 的设置中心风格
- Agent Hub、AgentSpec 列表沿用 3001；点节点打开右侧运维抽屉，可快速查看和修改，抽屉内可进入完整页面
- 上下文构成沿用 3001 的一页三栏
- System Prompt 独立成页并加版本管理，标出使用中的版本
- 调试台沿用 3001
