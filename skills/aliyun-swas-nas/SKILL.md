# 轻量应用服务器挂载通用型 NAS

先读 `wiki/aliyun-swas-nas-mount.md`。下面是操作顺序。Percolation 已经挂好，不要再建一套；复用 `/mnt/percolation`。

## 确认是哪台机器

1. 到轻量应用服务器控制台核对公网地址、内网地址和主机名。ECS 实例列表为空不能说明机器不在这个账号。
2. 读实例元数据 `vpc-id`、`zone-id`、`private-ipv4`。这个 `vpc-id` 在用户的专有网络列表里找不到，它是阿里云托管的发起端网络。
3. 打开轻量应用服务器「内网互通」，看发起端网段。广州常见为 `172.16.0.0/12`。

## 准备一块不重叠的专有网络

接收端网段和发起端重叠时，对等连接可以显示已激活，但 NAS 地址不可达。

1. 若账号里只有 `172.16.0.0/12` 的默认专有网络，新建专有网络，网段用 `10.0.0.0/16` 这一类不重叠的私网。
2. 交换机建在 NAS 购买页提供的可用区。广州容量型购买页目前只有可用区 A。
3. 保留已有的重叠对等连接，不要删。另加一条到新专有网络的内网互通。该地域第一次开通会停机约 1 分钟；已有连接时再加一条不会停机。

## 创建文件系统

购买页商品为通用型 NAS 按量（容量型）。建议：

- 地域与轻量服务器相同，协议 NFS
- 挂载点放在新建的专有网络和交换机上
- 回收站开启，保留时间宜短
- 生命周期、云备份先关闭
- 权限组用 VPC 默认权限组（全部允许）

创建后用控制台接口或挂载点列表拿到域名和内网地址。域名形如 `{文件系统ID}-{后缀}.cn-guangzhou.nas.aliyuncs.com`。

## 挂载

1. 安装 `nfs-common`。
2. 用 TCP 2049 探测挂载点内网地址。不要用 ping 判断，NAS 通常不回应 ICMP。
3. 挂载：

```bash
mount -t nfs -o vers=4.0,rsize=1048576,wsize=1048576,hard,timeo=600,retrans=2,noresvport \
  <挂载域名>:/ /mnt/<目录>
```

4. 写入一个测试文件再删掉，确认可写。
5. `/etc/fstab` 使用同一组选项，并加上 `_netdev,nofail`。然后执行 `mount -a` 验证。
